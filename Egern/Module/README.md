# Egern modules

`tag.sgmodule` mirrors a third-party Surge module, with a local description (“辅助 TAG 连接外网使用的模块。”), for Egern's compatible module importer. All other upstream module contents are preserved. The sync workflow checks once daily at 13:17 Beijing time (05:17 UTC) and commits only validated, changed content. It does not execute or audit the module. A download or validation failure preserves the last good file. Do not enable an unreviewed module, especially MITM and remote scripts; those scripts are not mirrored separately. A file is created only after the first successful fetch. GitHub Actions schedules may be delayed. Public mirroring is subject to the upstream author's distribution permissions.
