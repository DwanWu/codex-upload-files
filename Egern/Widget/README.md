# Egern 小组件维护说明

四个组件统一公开版本为 v2.0（脚本订阅版本参数 `v=2.0`，修订号 `rev` 仅用于更新缓存）。仅统一版本标识，不改变各组件现有功能、UI、缓存格式和执行配置。

- 智能热搜 v2.0：仅使用 AIHOT 官方 `title` 字段（不读取摘要或事件综述），保留热榜顺序、去重及24小时精选/最新动态补足。小号/中号目标5条、大号8条；原始标题单行左对齐，无行间分隔线，按估算宽度自适应字号，无法完整容纳且字号会低于可读下限、或原文含省略号的标题跳过，由后续真实资讯补足，不截断、不改写。保留ETag、429/503退避、6小时缓存及原订阅。旧缓存只保留标题列表。正常热榜足够时仅需1次网络请求，无事件详情请求。官方文档：https://aihot.news/agent?tab=api
- 黄历查询：脚本内预载经真实双源解析及本地农历核验的当月和下月逐日黄历，覆盖日期内无需联网即可显示宜忌。每天北京时间06:17由 GitHub Actions 校验并更新内嵌数据（调度可能延迟）；当月不完整保留已发布脚本；下月尚未发布完整时不阻塞当月，继续定时补齐。超出预载范围时，双源 GitHub Raw 并发请求（15秒）及各自 Contents API 备用入口（10秒），保留日期核验、月度缓存、30分钟退避及本地农历兜底；失败日志记录来源和错误。订阅地址及界面保留。宜忌仅为传统历法参考。
- 节点体检：恢复北京时间2026年11月26日结束时的版本。使用 IPPure 获取出口信息，失败时使用 ipify；优先使用 IPPure 风险值换算纯度，缺失时使用 IPQuery 风险值。保留原有居中卡片布局和底部内网、出口 IP 显示。
- 原订阅 URL 不变。回归命令：`node scripts/test_egern_widgets.mjs`；测试使用模拟网络，节点体检按恢复版本的默认入口验证三个组件尺寸与出口备用流程。
